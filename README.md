# STM32F303K8

## NUCLEO-F303K8 から BNO085 を動かす

## 目的

このリポジトリの目的は、NUCLEO-F303K8（Nucleo-32、MB1180）からBNO085を動作させ、センサーとの通信とデータ取得を確認することです。添付写真のセンサーモジュールには「GY-BNO080X」と表示されていますが、搭載チップがBNO080かBNO085かは未確認です。

まずは動作確認に必要な最小構成を目指します。依頼されていない機能は追加せず、機能や設定を実装・変更する前に内容を提案し、了承を得てから作業します。作業上のルールは [AGENTS.md](AGENTS.md) を参照してください。

## 参考リポジトリ

- [stm32-bno085-spi-shtp](https://github.com/embedded-craft-dong/stm32-bno085-spi-shtp/tree/main)

参考リポジトリはSTM32F407ZGとSTM32 HALを使うBNO085 SPI/SHTPドライバの例です。そこに記載されたF407向けピン配置やクロック・DMA設定は、このプロジェクトのSTM32F303K8向け設定を示すものではありません。採用する通信方式と配線は、対象ボードおよびBNO085モジュールを確認して決めます。

## 取り込んだドライバ

参考リポジトリから、動作確認の土台として次のファイルを取り込んでいます。

- `BNO085_Driver/Inc/bno085.h`、`BNO085_Driver/Src/bno085.c`：BNO085のSHTP/SH-2共通ドライバ
- `BNO085_Driver/Port/bno085_port.h`：MCU依存処理と共通ドライバ間のインターフェース
- `BNO085_Driver/Port/STM32/`：STM32 HALを使うポート層
- `LICENSE`：取り込んだコードに適用されるBSD-3-Clauseライセンス

STM32ポートのHALヘッダー参照はSTM32F3 HAL向けに変更しています。F407用のピン割り当て、`.ioc`、アプリケーション例、DMA/割り込み設定は取り込んでいません。CubeIDEプロジェクトへの組み込み、対象ボードでの設定、ビルドと実機確認は未完了です。ライセンス条件に従い、上流の著作権表示とライセンス文を保持してください。

## SPI接続案

以下は写真とボードのピン機能から作成した候補で、まだ配線・通電・実機確認をしていません。モジュールのPS0/PS1ストラップ状態とVCC許容電圧を確認してから確定してください。

| GY-BNO080X端子 | NUCLEO-F303K8端子 | 用途 |
|---|---|---|
| SCL | PB3 / D13 | SPI1 SCK |
| SDA | PB4 / D12 | SPI1 MISO |
| ADD | PB5 / D11 | SPI1 MOSI |
| CS | PA11 / D10 | GPIOチップセレクト |
| INT | 空きGPIO | 割り込み入力 |
| RST | 空きGPIO | センサーリセット |
| PS1 | 3.3 V | SPI選択時のストラップ候補 |
| PS0 | 空きGPIO | リセット時のSPI選択と起動後のWAKE制御 |
| BOOT | 3.3 V | 通常起動のストラップ候補 |
| GND | GND | 共通GND |

NUCLEO-F303K8のSPI1ピン対応は[STのNucleo-32ユーザーマニュアル](https://www.st.com/resource/en/user_manual/dm00231744-stm32-nucleo32-boards-mb1180-stmicroelectronics.pdf)、BNO08XのSPI信号とプロトコル選択は[BNO08Xデータシート](https://cdn.sparkfun.com/assets/2/b/9/0/6/DS-14686-BNO080.pdf)を参照しています。モジュール基板上の抵抗設定や電源回路は写真だけでは判別できないため、これらを確認するまでは接続を確定しません。

## 進め方

1. GY-BNO080Xの搭載チップ、PS0/PS1ストラップ、VCC許容電圧を確認します。
2. SPIなどの接続方式と、最初に確認する最小の出力を提案します。
3. ユーザーの了承後、その確認に必要な最小限のコード・設定だけを実装します。
4. ビルド結果と実機で確認できた内容を記録します。実機を使っていない場合は、その旨を明記します。

プロジェクトの作成・ビルド・書き込みにはSTM32CubeIDEを使用します。IDE上の具体的な設定や操作手順は、対象ボードと採用する通信方式を確認してから決めます。

各段階で追加機能が必要になった場合は、実装前に個別に提案して了承を得ます。
